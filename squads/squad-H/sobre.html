QUEM SOMOS

Unindo teoria acadêmica à excelência prática

Somos quatro desenvolvedores — Uilson Nasimento, Cleidiane Silva, João Gabriel França e Carla Paraguaio — cursando Análise e Desenvolvimento de Sistemas (ADS) na FICR. Combinamos rigor conceitual, boas práticas de engenharia de software e foco prático para resolver problemas complexos com soluções digitais elegantes.

Nosso ecossistema de trabalho valoriza a cooperação mútua: desde a estruturação semântica em HTML5 e arquiteturas de estilo em CSS3 até interfaces dinâmicas e integração full stack, cada membro contribui diretamente para o sucesso de cada entrega.

🌐 Front-End Moderno 🎨 CSS & UI Engineering ⚡ JavaScript / Node.js 📱 Responsividade Total 🐙 Git Colaborativo
