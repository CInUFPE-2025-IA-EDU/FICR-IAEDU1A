# Equipe de Desenvolvedoras

Portfólio acadêmico com páginas padronizadas, navegação responsiva e chatbot integrado ao Gemini.

## Executar

1. Crie o arquivo `.env` a partir de `.env.example`.
2. Preencha `GEMINI_API_KEY`.
3. Execute `npm start` ou `INICIAR.bat`.
4. Acesse `http://localhost:3000`.

## Modelo

`gemini-3.6-flash`

## Páginas

- Home
- Sobre
- Habilidades
- Projetos
- Serviços
- Depoimentos
- Case de Sucesso
- Contato
