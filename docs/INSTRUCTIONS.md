# Instrucoes - Squad B

O projeto mantido neste repositorio esta em `squads/squad-B`.

## Estrutura

- `metadata.json`: metadados do squad
- arquivos `.html`: paginas do projeto
- `styles/`: folhas de estilo das paginas

As paginas sao `home`, `sobre`, `contato`, `projetos`, `habilidades`,
`servicos`, `depoimentos` e `case-de-sucesso`.

## Desenvolvimento

Altere somente os arquivos dentro de `squads/squad-B`. Mantenha o HTML
semantico, o CSS responsivo e os caminhos relativos entre paginas e estilos.
